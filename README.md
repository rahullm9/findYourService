# Find Your Service

This is a full-stack web application designed to help users discover and offer local services. Built with React (Vite) on the frontend and Express.js with MongoDB on the backend.

## 🚀 Live Demo

**Visit the live application:** [Find Your Service on Vercel](https://find-your-service-nss5504tq-rahulmhtos-projects.vercel.app/)

## 🛠️ Technologies Used
- **Frontend**: React, Vite, Tailwind CSS
- **Backend**: Node.js, Express.js
- **Database**: MongoDB (Mongoose)
- **Deployment**: Vercel

## 📂 Project Structure
This repository features a unified monolithic structure optimized for Vercel deployment:
- `backend/` - Contains the Express server, API routes, database models, and the Vercel configuration. The frontend is built and served from within this directory.
  - `frontend/` - Contains the Vite React application source code.
